# Schema v1 freeze

Schema v1 is frozen. Additive changes only: a new field may be added (and
recorded in `CHANGELOG.md`), but a field may not be removed or change its
type. `.github/workflows/schema.yml` runs
`cargo test -p yashy-driver --test schema_diff` on every push, and that test
compares each command's current JSON against the golden payloads this
phase committed.

## Frozen commands

`check`, `verify`, `test`, `explain`, `doctor`, `expand`, `index`,
`context`, `mcp`, `bench` (the agent record).
