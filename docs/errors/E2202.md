# E2202 — unknown cfg key

`cfg(..)` takes a key the compiler defines: `windows`, `linux`, `macos`,
`unix`, `arch_x86_64`, `arch_aarch64`, `debug` and `release`. A misspelling is
an error, never a condition that quietly evaluates to false.

## Cause

Every other unknown name in the compiler is strict, and this one matters more
than most: a `cfg` whose key is not recognised would delete the code it guards
on every platform, silently. A program that does the wrong thing on one
platform because a branch vanished is far worse than a program that does not
compile, so the filter reports the key and the span it was written at.

## Example

```yashy
cfg(window) fn main() {
    print("this would never exist");
}
```

```text
windows_typo.ya:1:6
error[E2202]: unknown `cfg` key `window`
cfg(window) fn main() {
     ^^^^^^
note: known keys: windows, linux, macos, unix, arch_x86_64, arch_aarch64, debug, release
  docs: https://yashy.dev/errors/E2202
```

## Fix

Write the key you meant:

```yashy
cfg(windows) fn main() {
    print("this is Windows");
}
```

`yashy check --print-cfg` prints the keys that are true for the current target,
sorted, so a misspelling can be seen against the real set.
