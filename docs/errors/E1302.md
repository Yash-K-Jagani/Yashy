# E1302 — nondeterministic pure function

A `pure fn` reads a source whose value is not determined by its arguments.

## Cause

A pure function is a promise: the same arguments always give the same answer.
The builtins `now`, `time` and `rand` read a clock or the OS entropy source, so
a call to one of them breaks that promise. The effect pass already treats them
as I/O (`E1300`), but naming the rule helps: this is **DET-1**, a pure
computation may not read a nondeterministic source. A caller that needs a
timestamp or a random value must receive it as an argument, so the source is
visible at the edge of the program and a deterministic build can supply a fixed
one.

## Example

```yashy
pure fn stamp() -> int {
    return now();
}
```

```text
main.ya:2:12
error[E1302]: a pure fn cannot read a nondeterministic source: `now`
    return now();
           ^^^^^
  docs: https://yashy.dev/errors/E1302
```

## Fix

Remove `pure`, or pass the value in from an `io fn` caller:

```yashy
fn stamp(int instant) -> int {
    return instant + 1;
}
```

Under `YASHY_DETERMINISTIC=1` the clock is fixed at the process edge, so a
program that takes its time from a caller can be replayed byte for byte.
