# E0104 — bitwise operands have different types

A bitwise operator was applied to two integers of different types.

## Cause

Yashy has no implicit widening and no implicit conversion from `bool` to
`int`. `a & b` with an `int` on one side and a `bool` on the other has no
single result type. Two different C widths inside an `extern` signature have
the same problem: the result would have to be one of them.

## Example

```yashy
fn main() {
    const int a = 1;
    const bool b = true;
    const c = a & b;
}
```

```text
bits.ya:4:15
error[E0104]: cannot apply `&` to `int` and `bool`
    const c = a & b;
              ^^^^^
  docs: https://yashy.dev/errors/E0104
```

## Fix

Cast one operand so both have the same type: `a as int & b`, or
`a & (b as u8)` when the narrower type is the intended result.
