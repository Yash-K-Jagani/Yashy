# E1512 — inheritance is not in the language

An `object` (or `struct`) may not name a parent type. A type never gains a
parent: compose with an explicit field instead.

## Cause

Yashy's object model is Rust-style: traits are requirement sets, dispatch
is static, and there is no inheritance hierarchy to walk.

## Example

```yashy
object Dog : Animal { name: string }
```

```text
main.ya:1:16
error[E1512]: `Dog` cannot extend `Animal`: there is no inheritance; hold an `Animal` in a field
object Dog : Animal { name: string }
               ^^^^^^
  docs: https://yashy.dev/errors/E1512
```

## Fix

Replace the parent with a field and forward the calls you need:

```yashy
object Dog { animal: Animal, name: string }
```
