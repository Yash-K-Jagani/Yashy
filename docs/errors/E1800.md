# E1800 — manifest syntax

`yashy.toml` is outside the documented TOML subset, or it names a key or table
the manifest does not have.

## Cause

The manifest reader accepts a deliberately small TOML subset: tables, bare and
quoted keys, basic and literal strings, integers, booleans, arrays of those,
and comments. There are no inline tables, no multi-line strings, no dates and
no floats. A key outside the schema is refused rather than ignored — a
misspelled `[dependecies]` that silently disappears is a dependency the build
never sees.

Every error carries a line and a column, and the diagnostic names the key that
is wrong.

## Example

```text
yashy.toml:4:14
error[E1800]: `^1.2.3` is not an exact version; write `1.2.3` (a pin has no `^`, `~` or range)
http = "^1.2.3"
             ^
  docs: https://yashy.dev/errors/E1800
```

## Fix

Write the exact pin the error asks for (`http = "1.2.3"`), correct the key
spelling against the subset in the CLI reference, or remove the construct the
reader does not support. Run `yashy lock --check` afterwards; a manifest edit
that changes a version without updating the lock is
[E1802](E1802.md).
