# E0101 — equality in a comparison chain

`==` or `!=` appears inside a chained comparison, like `a == b == c`.

## Cause

A chain `a < b < c` means `a < b && b < c`, with each operand evaluated
once. Equality does not chain that way: `a == b == c` would compare a
boolean against `c`, which is not what the reader meant.

## Example

```yashy
fn main() {
    const bool ok = 1 == 1 == 1;
}
```

```text
chain.ya:2:21
error[E0101]: `==` cannot appear in a comparison chain: write the two comparisons separately with `&&`
    const bool ok = 1 == 1 == 1;
                    ^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0101
```

## Fix

Write the two comparisons separately with `&&`:

```yashy
const bool ok = 1 == 1 && 1 == 1;
```
