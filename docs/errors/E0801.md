# E0801 — private item used from another module

A module's items are private unless marked `pub`. Using a private function,
type, method, or field from another module is an error, not a warning: the use
is where the mistake is visible, while the declaration itself is fine.

## Cause

Every item records the module that declares it and whether it is `pub`
(`ItemOrigin`). A use whose module differs from the item's module, on an item
that is not `pub`, is refused with `E0801` naming both the item and the
module that hides it. A field follows the same rule, with its own `pub` on
the field: a `pub` struct with a private field is half-visible — the type may
be named, the field may not. A method follows the same rule: a `pub` type
does not publish its private methods.

## Example

```yashy
// lib.ya
fn helper() -> int { return 7; }
```

```yashy
// main.ya
import lib;
fn main() { print(helper()); }
```

```text
main.ya:2:24
error[E0801]: `helper` is private to module `lib`
fn main() { print(helper()); }
                       ^^^^^^
  docs: https://yashy.dev/errors/E0801
```

## Fix

Mark the item `pub` in its own module if it is meant to be shared, or move
the use into that module. For a field, mark the field `pub` (the struct
being `pub` is not enough).
