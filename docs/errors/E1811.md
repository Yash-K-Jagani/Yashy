# E1811 — dependency version not found

No non-yanked version of a registry package satisfies the version requirement in
the manifest.

## Cause

A `[dependencies]` entry names a registry package and a SemVer requirement. The
registry index is read before any source is fetched; if no published version
matches, or every matching version has been yanked, resolution stops with the
package name and the requirement instead of picking a near miss. A lockfile pin
that no longer names a published version is refused the same way.

## Example

```toml
[package]
name = "app"
version = "0.1.0"

[dependencies]
compress = ">=3.0.0"
```

```text
error[E1811]: no non-yanked version of `compress` satisfies `>=3.0.0` in the registry
  docs: https://yashy.dev/errors/E1811
```

## Fix

Widen the requirement to a published, non-yanked version, run `yashyc update` to
refresh the lockfile, or choose another package. `yashyc info <name>` reports the
versions the configured registry currently offers.
