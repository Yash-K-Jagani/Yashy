# E0106 — `repr(C)` is not allowed here

A `repr(..)` clause was written in front of something that has no
representation to choose, or it named a representation the language does not
have.

## Cause

`repr(C)` is a promise about memory: the fields of the type are laid out by
C's rules, in declaration order, so a C function can read a value of the type
by naming the same fields. That promise is only meaningful for a type with
fields, and only when the type is one concrete type:

- a `struct`, an `object`, or a fieldless `enum` may be `repr(C)`;
- a `fn`, an `impl`, an `import`, or an `extern` block may not — there is no
  value of those to lay out;
- an `enum` with payloads may not: C's `enum` is a name for an integer, so
  there is no payload for C to see;
- `C` is the only representation that exists. `repr(Rust)`, `repr(packed)`
  and every other name are refused rather than silently ignored.

## Example

```yashy
repr(C) fn main() {
    print(1);
}
```

```text
repr.ya:1:1
error[E0106]: `repr(C)` cannot be applied to a function: only a `struct`, an `object` or a fieldless `enum` has a layout
  repr(C) fn main() {
  ^^^^^^^
  docs: https://yashy.dev/errors/E0106
```

An `enum` with a payload is the other common case:

```yashy
repr(C) enum Shape {
    Empty,
    Circle(f64),
}
```

```text
shape.ya:3:5
error[E0106]: `repr(C)` needs a fieldless `enum`: variant `Circle` of `Shape` has a payload
    Circle(f64),
    ^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0106
```

## Fix

Remove the clause, or give the type a shape C can represent.

```yashy
repr(C) enum Kind {
    Empty,
    Circle,
}
```
