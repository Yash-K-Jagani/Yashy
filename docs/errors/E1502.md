# E1502 — incomplete trait impl

An `impl Trait for Type` block must provide exactly the methods the trait
declares: every method the trait requires, no method it does not, and every
signature — parameter types and receiver kind included — as written.

## Cause

The checker resolves each trait method's signature with `Self` standing for
the implementing type, then compares it with the impl's method of the same
name. A missing method, an extra method, a different receiver (`self`
against `self: *mut T`), or a different parameter or return type is refused
with `E1502` naming the method and the two signatures.

## Example

```yashy
trait Show { fn show(self) -> string; fn short(self) -> string; }
struct Point { x: int }

impl Show for Point { fn show(self) -> string { return "p"; } }
```

```text
main.ya:4:1
error[E1502]: `Point` does not implement `Show.short`: missing from the impl
impl Show for Point { fn show(self) -> string { return "p"; } }
^^^^
  docs: https://yashy.dev/errors/E1502
```

## Fix

Add the missing method (or remove it from the trait if it is not required),
remove any method the trait does not declare, and match the trait's
parameter and receiver spellings exactly.
