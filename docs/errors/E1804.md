# E1804 — package audit failure

`yashy audit` found a package that violates one of its policies, such as a
missing license or a stray build script.

## Cause

An audit never runs code from a dependency. It only reads manifests and
trees, so a finding is a file-layout or metadata fact: every package can be
named, versioned, and checked by exact pin, source kind, and declared
license.

The audit also reports a lockfile mismatch as `E1802` and a manifest that
cannot be parsed as `E1800`; those codes keep their own meanings and their
own pages.

## Example

```text
error[E1804]: package `net`: missing license
  docs: https://yashy.dev/errors/E1804
```

## Fix

Add the missing `license` value to the package's `[package]` table. For a
stray `build.rs`, delete it or move the code into the package's Yashy
sources: a package is Yashy source, not a build script with libraries
attached.
