# E1519 — recursive type alias

A type alias is a transparent spelling for an existing type. Its expansion
cannot mention the alias itself, because there would be no finite type to
resolve it to.

## Cause

The alias's target names the alias, directly or inside a nested type.

## Minimal example

```yashy
type Loop = Option[Loop];
```

## Fix

Break the cycle with a struct or enum that has its own name. A recursive
*value* type is written with a pointer or an owning container, not with an
alias to itself.
