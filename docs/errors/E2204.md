# E2204 — stale context pack revision

A context pack was cut from a different workspace revision than the caller
expected.

## Cause

Every structured pack names a `revision`: a stable hash of the index model's
files, symbols, imports and tests. An agent that plans edits from a pack has to
know the workspace still matches it. If a file, symbol, import or test changed
after the pack was cut, its excerpts may point at spans that no longer hold the
text they quote, and applying an edit from it could overwrite another writer's
work.

## Example

```text
$ yashyc context --task "fix check" --mode focus --expect-revision abc123 .
error[E2204]: stale context pack revision: expected `abc123`, workspace is `9f0e...`
  docs: https://yashy.dev/errors/E2204
```

## Fix

Cut a fresh pack and read its `revision`, then pass that value back with
`--expect-revision` when the edits are applied. The check is a refusal, not a
retry: a stale pack is never silently refreshed, because its caller may have
already reasoned from the older excerpts.
