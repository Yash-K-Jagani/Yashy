# E0702 — duplicate argument

A parameter is given twice in one call.

## Cause

Each parameter has one slot in the call. `f(a: 1, a: 2)` and `f(1, a: 2)`
both fill the slot for `a` twice, so one of the two values would be silently
discarded.

## Example

```yashy
fn f(int a, int b) -> int {
    return a + b;
}

fn main() {
    f(1, a: 2);
}
```

```text
main.ya:7:9
error[E0702]: parameter `a` is given twice
    f(1, a: 2);
    ^^^^^^
  docs: https://yashy.dev/errors/E0702
```

## Fix

Pass each parameter once: as one positional argument, as one named argument,
or as a default the call omits.
