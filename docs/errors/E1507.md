# E1507 — associated function called through a value

`p.origin()` calls a function with no receiver as if it were a method. An
associated function belongs to the type, not to any value of it, so it is
called through the type name.

## Cause

`check_user_method_on` finds the member by the receiver's type and asks
whether it takes a receiver. A receiver-less function found that way is
`E1507`: the call spelling promises a method, and the member is not one.

## Example

```yashy
struct Point { x: int }
impl Point { fn origin() -> Point { return Point { x: 0 }; } }

fn f(Point p) -> Point { return p.origin(); }
```

```text
main.ya:4:31
error[E1507]: `origin` is an associated function; call it as `Point::origin()`
fn f(Point p) -> Point { return p.origin(); }
                            ^^^^^^^^^
  docs: https://yashy.dev/errors/E1507
```

## Fix

Call it through the type: `Point::origin()`. If `origin` needs the value,
give it a `self` parameter so it is a method.
