# E0202 — duplicate field

A struct literal writes the same field twice.

## Cause

Each field has one value in a literal. Writing `x` twice leaves the checker
with two candidates for one slot, so the literal is refused rather than
guessing which one wins.

## Example

```yashy
struct Point {
    x: int,
    y: int,
}

fn main() {
    const p = Point { x: 1, x: 2, y: 3 };
}
```

```text
dup.ya:7:29
error[E0202]: duplicate field `x` in struct `Point`
    const p = Point { x: 1, x: 2, y: 3 };
                            ^
  docs: https://yashy.dev/errors/E0202
```

## Fix

Write each field once. If one value should win over another, keep only the
one that should be used.
