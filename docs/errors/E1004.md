# E1004 — arena value freed individually

A value owned by an `arena { }` block is freed with `.free()`, but the block
frees it all at exit.

## Cause

An explicit arena block owns every allocation written inside it. When the
block ends it releases the whole arena in one call, so an individual `.free()`
on one of those values frees the same memory twice. The second free is a
double free.

The verifier checks this before the program runs. `E1004` is reported where a
value allocated in an `arena { }` block is freed on its own. Values allocated
outside any arena are unaffected: they still need (and still accept) an
individual free.

## Example

```yashy
fn main() {
    arena {
        let buf = alloc(16);
        buf.free();
    }
}
```

```text
main.ya:4:13
error[E1004]: arena value `buf` is freed individually; the `arena { }` block frees it
    buf.free();
    ^^^^^^^^^
  docs: https://yashy.dev/errors/E1004
```

## Fix

Drop the individual free and let the block release the value.

```yashy
fn main() {
    arena {
        let buf = alloc(16);
    }
}
```

Nothing to write: the block ends, the arena is freed, and every allocation
inside it is released exactly once.
