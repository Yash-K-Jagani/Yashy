# E1524 — not a constant

A constant initializer or const fn call named a run-time value.

## Cause

A const is computed by the compiler. A binding, a parameter or an ordinary function has no value until the program runs, so the compiler cannot substitute one.

## Example

```yashy
fn f() { let n = 9; const bad = square(n); }
```

```text
main.ya:1:1
error[E1524]: A constant initializer or const fn call named a run-time value.
  docs: https://yashy.dev/errors/E1524
```

## Fix

Pass a literal or another constant, or make the binding a `const`.
