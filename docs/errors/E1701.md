# E1701 — task handle escapes its scope

A `Task[T]` handle must not outlive the `scope` that owns it.

## Cause

`scope` joins or cancels every child before execution continues past it, so a
handle created inside a `scope` has no meaning outside it: by the time the
scope is left, the child has already completed or been cancelled. Returning
such a handle, storing it in a struct field that lives on, or moving it into a
collection that outlives the scope would hand the caller a frame the scope has
already torn down.

## Example

```yashy
async fn g() -> int { return 1; }

async fn f() -> int {
    scope {
        let t = spawn(g);
    }
    return t;
}
```

```text
main.ya:6:12
error[E1701]: task handle `t` escapes its scope
scope {
    let t = spawn(g);
}
            ^
  docs: https://yashy.dev/errors/E1701
```

## Fix

Await the task inside the scope, where its result is still yours to keep:

```yashy
async fn f() -> int {
    scope {
        let t = spawn(g);
        return t.await;
    }
}
```

Only the result crosses the boundary, never the handle.
