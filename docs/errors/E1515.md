# E1515 — operators cannot be overloaded

An operator is only defined for built-in types. Writing `a + b` where `a`'s
type declares an `add` method is not in the language.

## Cause

Operators are total, checked, and fixed per operand type. A user type
cannot redefine what `+` means, so the spelling would promise one
computation and mean another.

## Example

```yashy
struct V { n: int }
fn main() { let a = V { n: 1 }; let b = V { n: 2 }; let c = a + b; }
```

```text
main.ya:3:54
error[E1515]: `+` is not defined for `V`: call the method `a.add(b)` instead
fn main() { let a = V { n: 1 }; let b = V { n: 2 }; let c = a + b; }
                                                     ^
  docs: https://yashy.dev/errors/E1515
```

## Fix

Call the method by name:

```yashy
let c = a.add(b);
```
