# E1500 — unknown trait

An `impl Trait for Type { .. }` block names a trait. If no trait with that
name is declared — in this module or any module it imports — the block
implements nothing, and there is nothing to check its methods against.

## Cause

The checker keeps a table of declared traits. A trait impl whose trait is not
in that table is refused with `E1500` before its methods are compared
against anything, because there is nothing to compare them against. When a
declared trait has a similar name, the diagnostic offers it as a label.

## Example

```yashy
struct Point { x: int }

impl Shw for Point { fn show(self) -> string { return "p"; } }
```

```text
main.ya:3:6
error[E1500]: no trait named `Shw`
impl Shw for Point { fn show(self) -> string { return "p"; } }
     ^^^
  did you mean `Show`?
  docs: https://yashy.dev/errors/E1500
```

## Fix

Declare the trait (`trait Show { fn show(self) -> string; }`), import the
module that declares it, or spell the name the way it is declared.
