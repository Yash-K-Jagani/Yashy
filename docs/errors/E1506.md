# E1506 — method called through a type

`Point::get()` names a method, and methods take a receiver. A type path
names one of the type's associated functions — functions with no receiver —
so a receiver-taking member must be called on a value instead.

## Cause

The checker resolves `Type::name` through the impl table the method call
uses. Finding a function that takes a receiver through a type path is
`E1506`: the spelling promises an associated function and the found member
is not one.

## Example

```yashy
struct Point { x: int }
impl Point { fn get(self) -> int { return self.x; } }

fn f() -> int { return Point::get(); }
```

```text
main.ya:4:29
error[E1506]: `get` is a method; call it on a value: `p.get()`
fn f() -> int { return Point::get(); }
                        ^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1506
```

## Fix

Call it on a value: `p.get()`. If `get` is meant to be callable without a
receiver, remove the `self` parameter so it is an associated function.
