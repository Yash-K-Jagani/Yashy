# E1404 — assumption not reported

The program was verified with trust assumptions but no inventory was requested.

## Cause

A proof rests on what it does not prove. An `extern` declaration, an `unsafe`
call and an explicit `unsafe { }` block are all places where the program trusts
something the verifier cannot see. Rule **ALIAS-5** says every such assumption
must be reported: a "verified" binary that quietly trusts C is a claim nobody
can audit. `yashyc verify --inventory` prints the list, with a reason for each
row; `--json` carries the same list in `assumptions`.

## Example

```text
$ yashyc verify --require-inventory libc.ya
warning[E1404]: 3 assumption(s) were not reported; add `--inventory` to list them
  docs: https://yashy.dev/errors/E1404
```

## Fix

Ask for the inventory and read it:

```text
yashyc verify --inventory libc.ya
yashyc verify --json --inventory libc.ya
```

Each row names the kind (`extern_decl`, `unsafe_call` or `unsafe_block`), the
name it trusts and the reason. The inventory never changes the exit code: the
program was accepted before the flag existed and is still accepted with it.
The warning is emitted only when `--require-inventory` is passed, so a project
can make the audit mandatory in CI without changing every caller.
