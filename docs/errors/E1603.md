# E1603 — duplicate macro name

Two macros share one name, or a macro name collides with a function in the
same module.

## Cause

An invocation resolves by name, so one name can only expand one way. A second
declaration with the same name would make the choice depend on which one the
expander happened to read first.

## Example

```yashy
macro unless { $cond:expr => { if $cond { } } }
macro unless { $cond:ident => { if $cond { } } }
```

```text
main.ya:2:1
error[E1603]: macro `unless` is already declared
macro unless { $cond:ident => { if $cond { } } }
^^^^^
  docs: https://yashy.dev/errors/E1603
```

## Fix

Rename one of the declarations. Macros and functions share the module's
namespace for this purpose: an invocation is a name, and a name should only
mean one thing.
