# E0602 — invalid range pattern

A range pattern's bounds are not both `int` or both `char`, or its start is
greater than its end.

## Cause

A range pattern is a closed test over a value that has a decidable order. Yashy
only admits `int` and `char` ranges, so both bounds must be written in the same
spelling and the lower bound must not exceed the upper one. Floating-point
ranges are rejected because membership is not exact and the pattern must stay a
test, never a comparison that quietly rounds.

## Example

```yashy
fn grade(int score) -> string {
    return switch score {
        case 90..=100 { "A" }
        case 1.0..2.0 { "not a range" }
        default { "F" }
    };
}
```

```text

        case 1.0..2.0 { "not a range" }
             ^^^^^^^^^

```

## Fix

Write the bounds in one ordered spelling, lower bound first:

```yashy
case 90..=100 { "A" }
case 'a'..='z' { "lowercase" }
```

Use `..` for a half-open range and `..=` to include the upper bound.
