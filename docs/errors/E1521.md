# E1521 — constant division by zero

A constant expression divided an integer by zero.

## Cause

Division by zero has no value. The compiler reports it at the call that wanted the constant, even when the zero comes from a nested const fn.

## Example

```yashy
const fn f() -> int { return 8 / 0; }
fn main() { const x = f(); }
```

```text
main.ya:1:1
error[E1521]: A constant expression divided an integer by zero.
  docs: https://yashy.dev/errors/E1521
```

## Fix

Make the divisor a nonzero literal, or move the division to run time where it is a checked fault.
