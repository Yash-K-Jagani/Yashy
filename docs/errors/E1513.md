# E1513 — there is no Drop

`impl Drop for T { .. }` is not in the language. Release is `defer` and
`.free()`, written at the owning scope.

## Cause

A destructor hook would run at an invisible point. Yashy releases values
where the reader can see the release: `defer` at scope exit, `.free()` for
the built-in linear types.

## Example

```yashy
impl Drop for Counter { fn drop(self) { } }
```

```text
main.ya:1:6
error[E1513]: there is no `Drop`: release with `defer` and `.free()` instead
impl Drop for Counter { fn drop(self) { } }
     ^^^^
  docs: https://yashy.dev/errors/E1513
```

## Fix

Write the release in the function that owns the value:

```yashy
fn main() {
    let xs = []int { 1, 2, 3 };
    defer { xs.free(); }
}
```
