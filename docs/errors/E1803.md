# E1803 — package missing from the offline store

A required package is not in the local store, and `--offline` forbids fetching
it.

## Cause

`--offline` is a promise that the build never touches the network or invokes
git, including for the package index. A package that has not been fetched into
the store cannot be built, so the build stops and names the package, its exact
pin and the command that would fetch it. Silently reaching for the network is
exactly what `--offline` exists to prevent.

The same code covers a git dependency whose `rev` cannot be checked out: the
URL and rev are printed so the pin can be corrected.

## Example

```text
error[E1803]: `http` 0.3.1 is not in the local store; run `yashy fetch` without `--offline` (or `yashy update`) first
  docs: https://yashy.dev/errors/E1803
```

## Fix

Run `yashy fetch` once with network access, then build with `--offline`. If the
package is a git dependency, check that the `rev` names a commit that exists:
the fetcher prints the URL and the rev it tried.
