# E0701 — unknown named argument

A named argument in a call names no parameter of the callee, or a positional
argument follows a named one.

## Cause

Named arguments are resolved against the callee's parameter names, in source
order. `f(c: 1)` fails because `f` has no parameter `c`. A positional argument
after a named one is ambiguous about which parameter it fills, so the call
must write every argument after the first named one by name too.

## Example

```yashy
fn f(int a, int b) -> int {
    return a + b;
}

fn main() {
    f(c: 1, a: 2);
}
```

```text
main.ya:7:5
error[E0701]: unknown named argument `c`; the parameters are `a`, `b`
    f(c: 1, a: 2);
    ^^^^
  docs: https://yashy.dev/errors/E0701
```

## Fix

Rename the argument to a parameter the callee declares, or drop the name and
pass the argument positionally before any named argument.
