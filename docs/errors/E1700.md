# E1700 — await or spawn outside an async function

`await` and `spawn` can only appear inside an `async fn`.

## Cause

`await` suspends the enclosing task until the one it drives is ready, and
`spawn` starts a new task on the executor. Both need somewhere to suspend, so
both belong to an `async fn` and nowhere else. In a synchronous function
there is no frame to suspend, and a task started there would have no owner.

The parser accepts `await` and `spawn` wherever an expression can appear;
whether one may actually appear here is this check's job.

## Example

```yashy
async fn fetch() -> int { return 1; }

fn main() {
    let n = fetch().await;
}
```

```text
main.ya:4:17
error[E1700]: `await` outside an `async fn`
fn main() {
    let n = fetch().await;
               ^^^^^
  docs: https://yashy.dev/errors/E1700
```

## Fix

Make the enclosing function `async`, or drive the task where one already
runs:

```yashy
async fn main() {
    let n = fetch().await;
}
```

`spawn` follows the same rule: a `spawn` outside an `async fn` is `E1700`
too, with the same fix.
