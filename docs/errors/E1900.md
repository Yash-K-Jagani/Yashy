# E1900 — sandbox capability denied

A sandboxed program tried to use a capability it was not given.

## Cause

`yashy run --sandbox` runs the program with a default-deny capability set:
`--allow-read` and `--allow-write` name the only paths it may touch, and
network and child processes are off unless requested. A file read or write
outside the allowlist is refused by the runtime's file entry points before
the file is opened, and the refusal names the capability that was denied.

## Example

```text
main.ya:3:11
error[E1900]: sandbox capability denied: file read outside the allowlist
    read_file("/etc/passwd");
    ^^^^^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1900
```

## Fix

Run with a wider allowlist (`--allow-read <path>`), or keep the file inside
the workspace. The capability checked is read, write, network or spawn; the
diagnostic names which one.
