# E1807 — package policy denial

A package names a license or source outside the project's audit policy.

## Cause

The `[audit]` table in `yashy.toml` lists allowed licenses and packages; a dependency falls outside that list.

## Minimal example

```toml
[audit]
allowed-licenses = ["MIT"]
```

## Fix

Change the dependency to an allowed package or license, or update the policy deliberately.
