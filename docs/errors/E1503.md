# E1503 — unsatisfied bound

A type parameter's bound is a promise the *caller* must keep: every argument
type must implement each bound trait. There are two places the promise is
checked — the call site, where the concrete argument is known, and inside a
generic body, where a method on a type parameter may only come from one of
its bounds.

## Cause

At a call site the checker looks for an `impl Trait for Type` for each
(bound, argument type) pair; a missing one is `E1503` naming the type, the
trait, and the file beside whose type declaration the impl belongs. Inside
a generic body, the body is checked per instantiation, so a method call on
a type-parameter binding resolves only through the bounds in force: if no
bound provides it, the call is `E1503` naming the missing bound — the trait
whose impl on the concrete type provides the method, when there is one.

## Example

```yashy
trait Show { fn show(self) -> string; }
struct Secret { x: int }

fn show_it[T: Show](T x) -> string { return x.show(); }

fn main() -> string { return show_it(3); }
```

```text
main.ya:7:29
error[E1503]: `int` does not implement `Show` required by `show_it`
fn main() -> string { return show_it(3); }
                            ^^^^^^^^
  docs: https://yashy.dev/errors/E1503
```

## Fix

Implement the bound for the argument type (`impl Show for Secret { .. }`,
written beside the type's declaration), or pass an argument type that
already satisfies it.
