# E1805 — invalid package signature

A package signature is missing, names a key the reader does not trust, or does not match the artifact.

## Cause

The registry package was signed by a key outside the reader's trust set, or the artifact was changed after it was signed.

## Minimal example

```text
YASHY_TRUSTED_KEY=release:... yashyc fetch
```

An unknown key or a changed tarball is refused before extraction.

## Fix

Name the correct key in `YASHY_TRUSTED_KEY` or `YASHY_KEYRING`, or republish the package from its unchanged source.
