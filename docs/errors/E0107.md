# E0107 — `sizeof` or `alignof` names no known type

`sizeof(..)` and `alignof(..)` take the name of a type, not a value. The name
written is not a type this program can see, or the call did not take exactly
one argument.

## Cause

The argument is read as a type name: `sizeof(P)` asks about the type `P`, and
there is no expression inside the parentheses to evaluate. A type that is not
declared, not imported, or not spelled as a type is refused here rather than
resolved to something else.

`sizeof` and `alignof` also fold to a constant at compile time, so they only
work for types whose layout is fixed: a type that names an unknown field type
has no size to report.

## Example

```yashy
fn main() {
    print(sizeof(Point));
}
```

```text
size.ya:2:18
error[E0107]: `sizeof` names no known type: `Point` is not declared
    print(sizeof(Point));
                 ^^^^^
  docs: https://yashy.dev/errors/E0107
```

## Fix

Declare the type first, or name a type that exists. The C spellings are
available to these queries, so `sizeof(u8)` and `alignof(i64)` both work.

```yashy
struct Point {
    x: f64,
    y: f64,
}

fn main() {
    print(sizeof(Point));
}
```
