# E1806 — package SBOM mismatch

A package's SBOM is missing or does not describe the artifact it accompanies.

## Cause

The publisher did not write an SBOM, or the artifact changed after the SBOM was generated.

## Minimal example

```text
yashyc verify-package demo-1.0.0.tar.gz
```

## Fix

Republish the package with `yashyc publish --key-id <id>`, which writes the SPDX SBOM beside the tarball and signature.
