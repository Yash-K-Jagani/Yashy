# E1525 — compile-time assertion failed

`const_assert(condition)` was given a condition the compiler computed as false.

## Cause

A `const_assert` is a check on a fact the compiler already knows: a table size,
a layout constant, the result of a `const fn`, or an arithmetic identity. It is
evaluated at compile time, so a false condition means the program could never
have been correct — there is no run-time state that could make it true. The
compiler reports it now rather than shipping a binary that fails on every run.

## Example

```text
$ yashyc check bounds.ya
error[E1525]: compile-time assertion failed: `size_of(Point) == 16`
  --> bounds.ya:4:21
   |
 4 |     const_assert(size_of(Point) == 16);
   |                     ^^^^^^^^^^^^^^^^^
   |
   docs: https://yashy.dev/errors/E1525
```

## Fix

Correct the fact or the expectation:

```text
const_assert(size_of(Point) == 16);  // the layout the compiler actually reports
```

If the condition is not a compile-time value, the failure is a different code
(`E1524`): move the check to run time with `assert(condition)` instead.
