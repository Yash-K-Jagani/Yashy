# E2100 — doc comment with no item

A doc comment (`/// ...`) documents the item written directly below it: a
`fn`, `struct`, `enum`, `object`, `const`, or a method inside an `impl`. It
is stored, not interpreted, and read later by `yashy doc`. There is nothing
to attach it to when it precedes a statement, an expression, or the end of
the file, so the parser reports it instead of silently dropping it.

## Cause

`///` is lexed as a token rather than trivia so the parser can attach a run
of doc lines to the next item. The same token appearing where an item cannot
follow — inside a function body, or after the last item in the file — has no
attachment, and the parser reports `E2100` at the doc comment.

## Example

```yashy
fn main() {
    /// This documents nothing.
    let int x = 1;
}
```

```text
doc_before_let.ya:2:5
error[E2100]: a doc comment must sit above an item, not a statement
    /// This documents nothing.
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E2100
```

## Fix

Move the comment above the item it documents, or make it an ordinary comment
with `//`:

```yashy
/// Adds two numbers.
fn add(int a, int b) -> int {
    return a + b;
}
```
