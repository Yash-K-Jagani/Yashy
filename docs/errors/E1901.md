# E1901 — sandbox limit breached

A sandboxed program hit one of its resource limits.

## Cause

`yashy run --sandbox` takes `--time <ms>`, `--memory <mb>` and an output
cap. Breaching one is `E1901`, named by limit: time, memory or output. The
limits are enforced by the OS on each platform — a job object with a memory
cap on Windows, rlimits on Linux — plus the runtime's own counters for time
and output.

## Example

```text
main.ya:2:5
error[E1901]: sandbox limit breached: time (5000 ms)
    while true { }
    ^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1901
```

## Fix

Raise the limit (`--time`, `--memory`), or write a program that finishes
inside it.
