# E1202 — recursive stack reservation

A cycle of function calls reserves `stack_alloc` bytes, so an unbounded
recursion cannot fit the bounded stack frame.

## Cause

`stack_alloc` reserves bytes in the current frame. A function that calls itself
-- directly or through other functions -- repeats that reservation on every
call. With no bound on the depth, the total exceeds the frame limit no matter
how small each reservation is. The compiler refuses the cycle rather than let a
program fault at run time with no source position.

A recursion that reserves nothing is not refused by this rule; it can still
run out of stack at run time if it never terminates, but it cannot exceed the
`stack_alloc` frame guard.

## Example

```yashy
fn descend(int n) {
    let *mut int scratch = stack_alloc(16);
    if n > 0 {
        descend(n - 1);
    }
}

fn main() {
    descend(3);
}
```

```text
main.ya:2:5
error[E1202]: recursive call cycle reserves stack bytes in `descend`
    let *mut int scratch = stack_alloc(16);
        ^^^^^^
  docs: https://yashy.dev/errors/E1202
```

## Fix

Move the reservation out of the cycle: allocate before the first call and pass
the pointer down, or use `alloc` for heap storage that is released with
`free()`. If the recursion is bounded by a value the compiler can check, write
the loop as an iterative `while` instead.
