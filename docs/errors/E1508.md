# E1508 — unknown associated function

A type path names a function the type does not declare — neither an
inherent associated function nor one through its trait impls. The call is
refused with the nearest declared names suggested.

## Cause

`Type::name` resolves through the same impl table the method call uses.
An unknown function name there is `E1508`, with a "did you mean" label when
one is close.

## Example

```yashy
struct Point { x: int }
impl Point { fn origin() -> Point { return Point { x: 0 }; } }

fn f() -> Point { return Point::origin2(); }
```

```text
main.ya:4:31
error[E1508]: `Point` has no associated function `origin2`
fn f() -> Point { return Point::origin2(); }
         ^^^^^^^^^^^^^^^^^^^^^^
  did you mean `origin`?
  docs: https://yashy.dev/errors/E1508
```

## Fix

Spell the declared name. If the function does not exist yet, declare it as
an associated function (no `self` parameter) in the type's `impl` block.
