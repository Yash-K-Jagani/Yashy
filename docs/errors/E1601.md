# E1601 — macro expansion limit exceeded

Macro expansion stopped because it crossed the depth or size cap.

## Cause

Expansion is a pure function from token trees to token trees, and a macro can
expand to tokens that invoke another macro, including ITSELF. Depth 64 and an
expansion size of 1 MiB per invocation bound that work: past either cap the
invocation is refused rather than the compiler growing without bound. A
self-recursive macro reaches the depth cap because its output is expanded
again.

## Example

```yashy
macro again { $x:expr => { again($x) } }
fn main() { again(1); }
```

```text
main.ya:2:13
error[E1601]: macro expansion exceeded the depth limit of 64
fn main() { again(1); }
            ^^^
  docs: https://yashy.dev/errors/E1601
```

## Fix

Break the recursion, or reduce what one invocation produces. If a long chain
of distinct macros is intentional, split it: the cap is generous for syntax
shorthand and non-negotiable for a loop written in macros.
