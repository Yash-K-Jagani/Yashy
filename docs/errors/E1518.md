# E1518 — a range needs integer or character bounds

A range has a length, so its bounds must come from a type where the distance
between two values is always countable. `int` and `char` qualify; `float` does
not, because a half-open float interval has no total `len`.

## Cause

A `..` range wrote a floating-point bound, in a pattern or in an expression.

## Minimal example

```yashy
fn main() {
    switch 1.5 {
        case 1.0..2.0 { print("inside") }
        default { print("outside") }
    }
}
```

## Fix

Use integer or character bounds, or test the float interval directly with
comparisons. A `for` over a range always walks integers; there is no float
range value to construct.
