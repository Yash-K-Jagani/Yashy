# E1517 — invalid `is` comparison

`is` tests pointer identity or an enum variant. It is never value equality.

## Cause

The right side of `is` was not a pointer name for a pointer subject, or the
subject was a value type (`int`, `string`, a struct) where `is` has no meaning.
`==` is the only value comparison in Yashy, and `is` is not an overloadable
operator.

## Example

```yashy
fn f(int a, int b) -> bool {
    return a is b;
}
```

## Fix

Use `==` for value equality. Use `is` only to compare two pointers by address
(`p is q`, `p is not q`) or to test a variant (`opt is Some`,
`color is not Red`).
