# E1523 — constant evaluation too deep

A constant expression exceeded its recursion depth or call limit.

## Cause

A const fn may call another const fn, but the chain is bounded. A cycle would otherwise exhaust the compiler stack.

## Example

```yashy
const fn a() -> int { return b(); }
const fn b() -> int { return a(); }
fn main() { const x = a(); }
```

```text
main.ya:1:1
error[E1523]: A constant expression exceeded its recursion depth or call limit.
  docs: https://yashy.dev/errors/E1523
```

## Fix

Break the cycle with a base case that returns a literal.
