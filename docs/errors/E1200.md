# E1200 — grapheme index out of range

`char_at` and `substring` index a string by grapheme cluster, not by byte.
An index the verifier can prove is out of range — negative, or at or past
the cluster count — is a compile error, because the program cannot get past
it. An index it cannot bound keeps its run-time fault.

## Cause

The verifier knows a string's cluster count when the string is written down
(a literal) or when its `graphemes()` result is tracked, and it knows a
constant index. Comparing the two settles the index: `char_at(5)` on a
three-cluster string is provably out of range, and `E1200` is reported at
the index.

## Example

```yashy
fn main() {
    let word = "abc";
    print(word.char_at(5));
}
```

```text
string_oob.ya:2:24
error[E1200]: grapheme index 5 is out of range for a string with 3 clusters
    print(word.char_at(5));
                       ^
  docs: https://yashy.dev/errors/E1200
```

## Fix

Index within the cluster count (`word.graphemes()` is the count), or check
the index before use. A `substring` range is clamped rather than faulty, so
only `char_at` reaches this code.
