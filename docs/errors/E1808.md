# E1808 — capability not granted

A call needs a capability the package did not grant in `[capabilities]`.

## Cause

The program uses a builtin that touches the world (`read_file`, `write_file`,
`getenv`, `now`, `spawn`, an `extern` call) without declaring the matching
capability. A missing declaration is no permission, never full access.

## Minimal example

```toml
[capabilities]
fs.read = ["data/*"]
```

The program may then read `data/x`; `data/../secret` is still refused because a
pattern matches one path segment only.

## Fix

Add the named capability to the manifest, or remove the call. The diagnostic
names the capability that would grant it.
