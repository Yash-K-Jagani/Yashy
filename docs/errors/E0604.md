# E0604 — break or continue names a label no enclosing loop has

A labeled `break` or `continue` exits a loop that carries that label: `break outer;` leaves the loop written `outer: for ..`. If no enclosing loop is labeled that way, there is nothing to jump to, so the checker reports the label instead of guessing the innermost loop.

## Cause

`break name;` and `continue name;` resolve `name` against the labels carried by the loops enclosing the statement. A label is visible only inside its own loop's body: once the loop ends, its labels are out of scope again.

## Example

```yashy
fn main() {
    outer: for i in 0..3 {
        for j in 0..3 {
            break middle;
        }
    }
}
```

```text
unknown_label.ya:4:13
error[E0604]: no enclosing loop is labeled `middle`; the labels in scope are: `outer`
            break middle;
            ^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0604
```

## Fix

Use the label of the loop you mean, or drop the label to leave (or continue) the innermost loop:

```yashy
fn main() {
    outer: for i in 0..3 {
        for j in 0..3 {
            break outer;
        }
    }
}
```
