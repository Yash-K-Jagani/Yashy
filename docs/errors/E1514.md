# E1514 — a trait has no fields

A trait is a requirement set with no state. `trait T { x: int }` is not in
the language.

## Cause

State belongs to a concrete type. A trait names only the methods its
implementors must provide, so two implementors can hold different state
and the trait never has to describe it.

## Example

```yashy
trait T { x: int }
```

```text
main.ya:1:11
error[E1514]: a trait has no fields: declare `x` on a struct or object instead
trait T { x: int }
          ^
  docs: https://yashy.dev/errors/E1514
```

## Fix

Declare the field on each implementing struct:

```yashy
struct Point { x: int }
```
