# E1403 — unproved view source

A view was asked for a source whose storage the compiler cannot keep alive.

## Cause

A view is a pointer and a length into storage something else owns. Its source
must be a binding the compiler can follow: the binding outlives the view, and
the borrow rule marks it so it cannot be moved or changed while the view exists.
A temporary dies at the end of the expression, and a field access is not a
source the current borrow rule tracks, so accepting either would create a view
that may point at freed or unrelated memory. This is rule **ALIAS-3**: a view is
used only when its relationship to the source is proved, never assumed.

## Example

```yashy
fn make() -> []int { return []int { 1, 2 }; }
fn main() { const v = make()[0..1]; }
```

```text
main.ya:2:17
error[E1403]: a view needs a binding as its source: a field or a temporary may not outlive the view
fn main() { const v = make()[0..1]; }
                        ^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1403
```

## Fix

Bind the source first and take the view from the binding:

```yashy
fn first() -> []int {
    const values = make_array();
    return values[0..2];
}
```

The view now borrows `values`, which stays alive for the function's frame, and
moving or mutating `values` while the view is used is refused by the borrow rule.
