# E0601 — unreachable switch arm

A `switch` arm matches no value, because an earlier arm already covers it.

## Cause

Arms are tried in order. When an earlier unguarded arm covers every value a
later arm matches — `case _` before `case Red`, or `case 0..=10` before
`case 5` — the later arm can never run. A guarded arm is still reachable even
when an earlier arm covers its pattern, because the guard may fail.

## Example

```yashy
enum Color {
    Red,
    Green,
}

fn code(Color c) -> int {
    return switch c {
        case _ { 1 }
        case Red { 2 }
    };
}
```

```text
match.ya:9:6
error[E0601]: unreachable switch arm; an earlier arm already covers it
    case Red { 2 }
    ^^^^^^^^
  label: this arm can never match; the earlier arm `_` already covers it
  docs: https://yashy.dev/errors/E0601
```

## Fix

Remove the dead arm, or move it before the arm that covers it.
