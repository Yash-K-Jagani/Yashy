# E1002 — spread operand used after the literal

A value spread into a struct or array literal is used again afterwards.

## Cause

`P { ..base }` and `[0, ..xs, 4]` move their spread operand as a whole:
its remaining fields, or every one of its elements, are taken out of it.
Version 1 does not track which individual field or element was read, so the
operand is spent and any later use would read or free a second time.

## Example

```yashy
struct Point {
    x: int,
    y: int,
}

fn main() {
    const base = Point { x: 1, y: 2 };
    const p = Point { ..base };
    const int z = base.x;
}
```

```text
moved.ya:9:22
error[E1002]: value `base` has already been moved by a spread
    const int z = base.x;
                     ^^^^
  docs: https://yashy.dev/errors/E1002
```

## Fix

Do not use the spread operand after the literal. Read the fields you need
first, or spread a copy made for that purpose.
