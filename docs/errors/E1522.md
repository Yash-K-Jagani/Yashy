# E1522 — constant evaluation out of fuel

A constant expression exceeded the compiler's step limit.

## Cause

The evaluator is bounded: a million expression steps is enough for a lookup table and far too little for a runaway loop. Hitting the cap is reported rather than followed into a compiler hang.

## Example

```yashy
const fn work() -> int { let int i = 0; while i < 2000000 { i = i + 1; } return i; }
fn main() { const x = work(); }
```

```text
main.ya:1:1
error[E1522]: A constant expression exceeded the compiler's step limit.
  docs: https://yashy.dev/errors/E1522
```

## Fix

Remove the unbounded recursion or loop, or compute the value at run time.
