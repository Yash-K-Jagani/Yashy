# E1510 — unused type parameter

A generic type's type parameter must be mentioned by at least one field or
variant payload. Declaring `T` and never using it is `E1510`.

## Cause

`Pair[i64]` and `Pair[string]` are different types only because their
fields differ. If the parameter appears nowhere, two instantiations would
have one layout and nothing to distinguish them, so the declaration is
refused where it is written instead of silently producing one type under
many names.

## Example

```yashy
struct Wrapper[T] { n: i64 }
```

```text
main.ya:1:16
error[E1510]: `Wrapper` declares type parameter `T`, but no field or variant payload uses it
struct Wrapper[T] { n: i64 }
               ^
  docs: https://yashy.dev/errors/E1510
```

## Fix

Use the parameter somewhere in the fields or payloads (`x: T`), or remove
it from the declaration if it was never meant to be generic.
