# E0102 — field default is not constant

A struct field default is not a literal or a `const` name.

## Cause

A default is inserted at every place the struct is built, so it cannot call
a function, read a parameter, or depend on the enclosing scope. Only a
literal or a top-level `const` name has the same value at every site.

## Example

```yashy
fn compute() -> int {
    return 3;
}

struct Config {
    retries: int = compute(),
}
```

```text
defaults.ya:6:5
error[E0102]: a field default must be a literal or a `const` name
    retries: int = compute(),
    ^^^^^^^^^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0102
```

## Fix

Write a literal (`= 3`) or name a `const` (`= DEFAULT_RETRIES`).
