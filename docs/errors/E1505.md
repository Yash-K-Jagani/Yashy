# E1505 — instantiation budget exceeded

A generic function may be instantiated at most 64 distinct substitutions,
and a program at most 4096 in total. One more is `E1505`, at the call site
that crossed the budget.

## Cause

Each instantiation is a whole function body the compiler checks and emits.
An unbounded family of them makes compile times unbounded, so the budget
turns a hang into a diagnostic. Identical substitutions reuse one symbol
and never count twice.

## Example

```yashy
fn id[T](T x) -> T { return x; }

fn main() -> int { return id(1) + id(2.0); }
```

```text
main.ya:3:29
error[E1505]: `id` was instantiated 65 times: the budget is 64 instantiations per function
fn main() -> int { return id(1) + id(2.0); }
                            ^^^^
  the first instantiation was at 3:29, this one at 3:41
  docs: https://yashy.dev/errors/E1505
```

## Fix

Specialize the generic function into fewer concrete ones called by name,
or split the call sites so each substitution is written once.
