# E1501 — conflicting trait impl

A trait has one implementation per type. Two `impl Trait for Type` blocks
for the same pair would give one call two possible targets, and static
dispatch has no way to choose between them.

## Cause

The checker records each `(trait, type)` pair it accepts. A second impl for
a pair already recorded is refused at the impl's header with `E1501`, before
any of its bodies is checked, so the diagnostic is one error about the
duplicate rather than a cascade of body errors.

## Example

```yashy
trait Show { fn show(self) -> string; }
struct Point { x: int }

impl Show for Point { fn show(self) -> string { return "a"; } }
impl Show for Point { fn show(self) -> string { return "b"; } }
```

```text
main.ya:5:1
error[E1501]: `Point` already implements `Show`: one trait has one impl per type
impl Show for Point { fn show(self) -> string { return "b"; } }
^^^^
  docs: https://yashy.dev/errors/E1501
```

## Fix

Remove the second impl, or move the shared logic into a free function that
both the inherent method and the trait method can call.
