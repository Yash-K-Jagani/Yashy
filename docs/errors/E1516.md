# E1516 — membership is not defined for this container

`needle in container` is never a new operator. It calls the container's own
`contains` method, so a type that does not document membership cannot be used
on the right of `in`.

## Cause

The right-hand side was a type without a `contains` method — an integer, a
struct, or a user type that has not defined one.

## Example

```yashy
struct Box { value: int }

fn f(Box b) -> bool {
    return 1 in b;
}
```

## Fix

Call a method the type actually defines, or give the type a `contains` method.
Membership is defined for strings (substring), slices and arrays (element),
maps (key) and, once they land, ranges and sets. `in` never overloads an
operator on a user type.
