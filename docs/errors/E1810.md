# E1810 — dependency source missing

A dependency's declared source does not name a readable package directory.

## Cause

A `path` dependency points at a directory that does not exist, or a lock entry
names a source that cannot be resolved on this machine. Resolution stops with
the dependency name and the source spelling rather than silently treating the
package as empty.

## Example

```toml
[package]
name = "app"
version = "0.1.0"

[dependencies.lib]
path = "missing"
```

```text
error[E1810]: `lib` is a path dependency at `missing`, which is not a directory
  docs: https://yashy.dev/errors/E1810
```

## Fix

Create the directory with its own `yashy.toml`, correct the `path`, or remove
the dependency. For a registry package, run `yashyc fetch` (with `--offline`
only when the package is already in the store).
