# E1600 — macro invocation matches no arm

A macro invocation names a declared macro, but none of its arms match the
tokens the caller supplied.

## Cause

A macro arm is a pattern over token trees. Matching is left to right: a literal
token or delimiter must agree, and a metavariable must match input of the
fragment kind it names. If the invocation has the wrong shape — a missing
argument, an extra argument, or an identifier where an expression was expected
— no arm matches, and the invocation is not expanded.

## Example

```yashy
macro unless { $cond:expr => { if $cond { } } }
fn main() { unless(ready, count) { } }
```

```text
main.ya:2:13
error[E1600]: macro `unless` has no arm matching `ready, count`
fn main() { unless(ready, count) { } }
            ^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1600
```

## Fix

Make the invocation match one arm's pattern, or add an arm for the shape
being used. A type or syntax error inside an expanded body is reported after
expansion, not here; here the tokens themselves did not fit any arm.
