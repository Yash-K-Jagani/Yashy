# E0606 — invalid fixed-array pattern

A fixed-array pattern names the wrong number of elements, or writes `..` more
than once.

## Cause

A `[T; N]` has a length the compiler knows, so a pattern over it must describe
exactly `N` elements. Written patterns before the `..` count up from zero and
the ones after it count down from the end, which makes every named element a
compile-time index. A bare `[a, b]` therefore has to name all `N`; `[a, ..]`
names the ones it wants and elides the rest. A single `..` is the only way to
say "and the other elements", so a second one has no meaning.

Only a fixed array can be destructured this way. A `[]T` view has no
compile-time length, so a pattern cannot name its elements.

## Example

```yashy
fn main() {
    let a = [1, 2, 3];
    let [first, second] = a;
}
```

```text
main.ya:3:9
error[E0606]: this pattern names 2 elements, but `[int; 3]` has 3: write `..` to stand for the rest
    let [first, second] = a;
        ^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0606
```

## Fix

Name every element, or let `..` stand for the rest:

```yashy
let [first, second, third] = a;
let [first, ..] = a;
```
