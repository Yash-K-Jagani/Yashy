# E1520 — constant overflow

A constant expression overflowed an integer type.

## Cause

The operation is checked exactly as it would be at run time. A constant that does not fit its type is a compile error, never a wrapped value.

## Example

```yashy
const fn f() -> int { return 9223372036854775807 + 1; }
fn main() { const x = f(); }
```

```text
main.ya:1:1
error[E1520]: A constant expression overflowed an integer type.
  docs: https://yashy.dev/errors/E1520
```

## Fix

Use a smaller literal, a wider type where one exists, or compute the value at run time.
