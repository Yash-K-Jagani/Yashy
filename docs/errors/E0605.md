# E0605 — two nested loops carry the same label

A label names the loop it is written on, and `break name;` / `continue name;` find it by walking outwards. If two loops nested one inside the other carry the same label, the inner one's label hides the outer one, so a jump meant for the outer loop could land on the inner one instead.

## Cause

Labels are scoped by nesting: an inner loop may reuse a label that no enclosing loop has, but it may not repeat a label already in scope, because then `break outer;` written inside the inner loop would be ambiguous between the two.

## Example

```yashy
fn main() {
    outer: for i in 0..3 {
        outer: for j in 0..3 {
            print(j);
        }
    }
}
```

```text
duplicate_label.ya:3:16
error[E0605]: the label `outer` is already in scope
        outer: for j in 0..3 {
               ^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0605
```

## Fix

Rename one of the two loops so every enclosing label is distinct:

```yashy
fn main() {
    outer: for i in 0..3 {
        inner: for j in 0..3 {
            print(j);
        }
    }
}
```
