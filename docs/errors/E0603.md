# E0603 — an `if let` pattern that always matches

`if let` and `while let` ask a question: does this value have this shape? A
pattern that matches every value of its type can never answer no, so the `else`
branch is dead code and a `while let` never ends. The checker reports the form
instead of compiling a branch it has proved unreachable.

## Cause

A pattern is irrefutable when no value of the subject's type can fail it:

- `_` and a plain name such as `x` match everything;
- a struct pattern that names every field of its variant matches everything the
  variant can hold;
- a variant, tuple-variant or struct-variant pattern is irrefutable only when
  the enum has exactly one variant and every payload pattern is irrefutable.

A literal never is. `Some` and `None` (and `Ok` and `Err`) are two variants, so
neither of them is.

## Example

```yashy
fn main() {
    const int answer = 42;
    if let x = answer {
        print(x);
    }
}
```

```text

    if let x = answer {
           ^

```

## Fix

Use `let` when there is nothing to test:

```yashy
fn main() {
    const int answer = 42;
    let x = answer;
    print(x);
}
```

`while let` says the same thing about its loop: a pattern that always matches
makes `while let x = next() { .. }` a `while true` with a binding, and the exit
has to be an explicit `break` in the body.
