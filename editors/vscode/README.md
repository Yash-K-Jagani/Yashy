# Yashy for VS Code

The extension is thin on purpose: the compiler is the only implementation of
the language. It contributes the generated TextMate grammar, a language
configuration, snippets, commands, a task provider and a debug configuration,
and starts `yashyc lsp --stdio` for everything an editor needs to know.

## Install

```text
cd editors/vscode
npm install
npm run compile
code --install-extension .
```

`yashyc` must be on `PATH`, or set `yashyc.path` to its absolute location.

## What it does

| Feature | Provided by |
|---|---|
| Syntax highlighting | `syntaxes/yashy.tmLanguage.json`, generated by `yashyc tokens --grammar editors` |
| Completion, hover, definition, rename, diagnostics | `yashyc lsp --stdio` |
| Format on save | the language server's formatting request, which calls `yashyc fmt` |
| `Yashy: Check file`, `Yashy: Run tests`, `Yashy: Doctor` | compiler verbs in a terminal |
| Tasks named in `yashy.toml` | `yashyc task <name>` |
| Debug | a DAP configuration that calls `yashyc debug` (available now: LLDB/cdb, symbol and function-entry-line breakpoints; typed in-function values still need per-instruction debug info) |

No grammar is written by hand here. Editing `syntaxes/yashy.tmLanguage.json`
directly is lost on the next regeneration; add the token to the lexer instead.
